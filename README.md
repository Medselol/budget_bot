# Учёт стройки в Telegram

Закрытый бот для записи денежных операций по дуплексам. Каждый приглашённый пользователь ведёт свой учёт; владелец видит также общие суммы. SQLite на Mac хранит данные, бот показывает отчёты в чате и CSV для Excel. По желанию он автоматически отражает все записи в Google Таблице. Интерфейс — на русском, суммы можно вводить в гривнах и долларах.

## Возможности

- Расход: объект → этап → тип затрат → касса → валюта (UAH или USD) → сумма → дата → комментарий → подтверждение.
- Приход: объект → источник денег → касса → валюта → сумма → дата → комментарий → подтверждение.
- Перевод между своими кассами в выбранной валюте: уходит из одной и приходит в другую, в приходах проекта не отражается.
- Отчёт за текущий месяц, весь период или произвольные даты; по одному объекту или всем объектам для кнопочных периодов.
- CSV с подробными операциями и итогами; открывается в Excel. Отдельно выделяются вложения и займы, оплаты покупателей, возвраты, расходы.
- Остатки по кассам отдельно в гривнах и долларах. Доступ только приглашённым Telegram ID, каждый работает в личном чате.
- У каждого добавленного пользователя свои объекты, кассы и операции. Владелец видит общий отчёт всех пользователей и разбивку по каждому.
- Кнопка «Операции» показывает последние 10 записей; свою операцию можно изменить через форму бота или удалить после подтверждения. Участники не могут менять записи друг друга.
- Если подключена Google Таблица, бот оформляет её в три вкладки: «Инструкция», «Операции» и «Итоги». Подробный журнал снабжён фильтрами, закреплённой шапкой, чередованием строк и отдельными колонками валюты и суммы; в итогах суммы разделены по пользователям и валютам.

## Пригласить пользователей

1. Каждый участник пишет боту `/start`. Пока его нет в списке, бот ответит его Telegram ID. Пусть пришлёт этот номер тебе.
2. Со **своего** Telegram аккаунта отправь боту `/adduser 123456789 Имя` (подставь настоящий ID и имя). После этого участник нажимает `/start` ещё раз.
3. Пользователь может добавить свой объект командой `/project Дуплекс №1` и записывать приходы и расходы. Даже если у двух пользователей объект называется одинаково, записи остаются раздельными.
4. Своё меню ты откроешь `/start`: «Мой отчёт», «Мои остатки», «Общий отчёт» и «Пользователи». Команда `/users` покажет список. Отключить доступ можно `/removeuser 123456789`; уже записанные операции останутся в общей истории.
5. Переименовать пользователя может владелец: `/renameuser ID Имя`, например `/renameuser 243705540 Денис`. Чтобы добавить Игоря, попроси его написать боту `/start` и прислать показанный ID, затем отправь `/adduser ID Игорь`.

ID владельца берётся из `OWNER_USER_ID` (или из первого ID в прежней строке `ALLOWED_USER_IDS`). Не передавай другим токен Telegram бота или файл `.env`.

## Подключить Google Таблицу

Google аккаунт и таблицу создаёшь **ты**: бот не может сделать это без твоего доступа к Google. Для бота достаточно прав редактора на одну конкретную таблицу; участникам доступ к общей Google Таблице не предоставляй, если хочешь оставить их учёт раздельным. Настройка основана на [официальной инструкции Google по сервисным аккаунтам](https://developers.google.com/workspace/guides/create-credentials) и [Google Sheets API](https://developers.google.com/workspace/sheets/api/quickstart/python).

1. В своём Google Drive создай **пустую** Google Таблицу, например «Учёт стройки». Скопируй полную ссылку из адресной строки (`https://docs.google.com/spreadsheets/d/ИДЕНТИФИКАТОР/edit`).
2. В [Google Cloud Console](https://console.cloud.google.com/) создай проект и [включи Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com) для этого проекта. Открой «IAM и администрирование» → «Сервисные аккаунты», создай сервисный аккаунт. Роль администратора не требуется.
3. Открой этот аккаунт → «Ключи» → «Добавить ключ» → «Создать новый ключ» → **JSON**. Браузер скачает файл. Никому не отправляй этот файл.
4. Скопируй адрес почты сервисного аккаунта (вид `...@...iam.gserviceaccount.com`). В своей Google Таблице нажми «Настроить доступ», добавь эту почту с ролью **Редактор**. Это разрешит боту записывать данные только в предоставленную таблицу.
5. Останови бота (`Ctrl+C`). Запусти мастер настройки, вставь **полную** ссылку на таблицу, а на запрос пути перетащи скачанный JSON файл из Finder прямо в окно Терминала и нажми Enter. Мастер скопирует ключ в папку бота с закрытым доступом и обновит `.env`, сохранив токен:

   ```bash
   cd ~/stroika-bot
   python3.15 setup_google.py
   ```

6. Установи пакет авторизации **один раз** в отдельную среду и запусти бота через неё:

   ```bash
   cd ~/stroika-bot
   python3.15 -m venv .venv
   .venv/bin/python -m pip install 'google-auth[requests]'
   .venv/bin/python run_mac.py
   ```

При первом запуске бот перенесёт уже существующие записи в таблицу. Далее новая запись появляется во вкладках «Операции» и «Итоги» после её сохранения в боте. Если Google временно недоступен, запись остаётся в SQLite, выгрузка повторится автоматически. Впоследствии запускать бота можно командой `cd ~/stroika-bot` и `.venv/bin/python run_mac.py`. Вкладки создаются автоматически. Изменения непосредственно в таблице **не импортируются обратно** в бот: вводи операции в Telegram.

При синхронизации бот переименует стандартный пустой лист Google Таблиц («Лист1»/«Sheet1») во вкладку «Инструкция». На ней объясняется назначение остальных вкладок. «Операции» — фильтруемый журнал; «Итоги» — отдельные суммы в гривнах и долларах по каждому участнику и общая сумма. Заголовки и валютные суммы форматируются автоматически.

## Обновление уже установленного бота

1. Останови бота в Терминале сочетанием `Ctrl+C`.
2. Сохрани копию папки `~/stroika-bot/data` в безопасном месте. Если её пока нет, пропусти этот шаг.
3. Распакуй новую версию архива в **отдельную** папку, затем скопируй файлы программы:

   ```bash
   mkdir -p ~/stroika-update
   unzip -o ~/Downloads/stroika_telegram_bot.zip -d ~/stroika-update
   cp ~/stroika-update/bot.py ~/stroika-bot/bot.py
   cp ~/stroika-update/sheets_sync.py ~/stroika-bot/sheets_sync.py
   cp ~/stroika-update/run_mac.py ~/stroika-bot/run_mac.py
   cp ~/stroika-update/setup_mac.py ~/stroika-bot/setup_mac.py
   cp ~/stroika-update/setup_google.py ~/stroika-bot/setup_google.py
   cd ~/stroika-bot
   python3.15 run_mac.py
   ```

   Если архив называется иначе, подставь его имя из папки «Загрузки». Файлы `~/stroika-bot/.env` и `~/stroika-bot/data/ledger.sqlite3` не трогай. Если бот ещё не настроен и `.env` пустой, сначала заполни токен через `python3.15 setup_mac.py`, а затем запусти команду выше. Если уже добавил Google Таблицу, используй `.venv/bin/python run_mac.py` вместо `python3.15 run_mac.py`.

Чтобы обновить только оформление Google Таблицы, достаточно заменить файл синхронизации и перезапустить бота: останови его `Ctrl+C`, скопируй новую версию `sheets_sync.py` в `~/stroika-bot`, затем выполни `.venv/bin/python run_mac.py`. При следующей синхронизации бот заполнит вкладку «Инструкция» и оформит журнал и итоги. Настройки `.env`, ключ Google и базу операций менять не нужно.

Чтобы добавить меню изменения операций, обнови из архива файлы `bot.py` и `sheets_sync.py` (последний нужен, чтобы изменения и удаления сразу синхронизировались с таблицей). База данных и настройки сохраняются. После перезапуска выбери в Telegram «Операции» → нужную запись → «Редактировать» или «Удалить».

## Запуск 24/7 на Railway

Railway запускает только процесс бота; твой Mac может быть выключен. Для постоянной работы создай там сервис из GitHub-репозитория с этой папкой. В корне репозитория должны лежать `bot.py`, `sheets_sync.py`, `requirements.txt` и `railway.toml`. Не загружай `.env`, `google-service-account.json` или базу `ledger.sqlite3` в GitHub.

1. В Railway создай проект и сервис из GitHub-репозитория бота. Railway прочитает `railway.toml`, установит зависимости из `requirements.txt` и запустит `python bot.py`.
2. В настройках сервиса открой **Variables** и добавь:

   | Переменная | Значение |
   | --- | --- |
   | `TELEGRAM_BOT_TOKEN` | Новый токен из BotFather; старый токен отзови |
   | `OWNER_USER_ID` | `243705540` |
   | `ALLOWED_USER_IDS` | `243705540` |
   | `BOT_DB_PATH` | `/data/ledger.sqlite3` |
   | `GOOGLE_SHEET_ID` | ID из ссылки Google Таблицы |
   | `GOOGLE_SERVICE_ACCOUNT_JSON` | Весь текст скачанного JSON-ключа целиком |

   У Google-переменной значение должно начинаться с `{` и заканчиваться `}`. Вставляй JSON только в секреты Railway, никогда в GitHub или этот чат. Если пока не подключаешь таблицу, пропусти две последние переменные.
3. Подключи к сервису **Volume** с точкой монтирования `/data`. База операций будет храниться там и переживёт новый запуск. Не меняй точку монтирования после запуска.
4. Нажми **Deploy** и дождись статуса **Active**. В **Logs** проверь, что бот стартовал и Google Таблица обновилась. Пока сервис запускается на Railway, останови локального бота на Mac сочетанием `Ctrl+C`: одновременно две копии с одним токеном работать не должны.

Railway указывает минимальную цену плана Hobby $5 в месяц; в неё включено $5 использования, перерасход оплачивается отдельно. Актуальные условия: [планы Railway](https://docs.railway.com/pricing/plans). У сервиса с SQLite обязательно подключи постоянный диск: [Railway Volumes](https://docs.railway.com/volumes).

## Запуск

Нужен компьютер или сервер с Python **3.10+**, доступом к Telegram Bot API и постоянным диском. Без Google Таблицы дополнительные Python-пакеты не нужны.

1. Бот уже создан. Токен, который отправляли в переписку, замени через [@BotFather](https://t.me/BotFather), выбрав своего бота в `/mybots` и пункт замены токена. Новый токен держи только у себя. ID из скриншота — `243705540` (профиль «Leo»); используй его, если будешь писать боту именно с этого аккаунта.
2. На Mac открой «Терминал», создай папку для бота и распакуй скачанный архив (если браузер сохранил его в «Загрузки»):

   ```bash
   mkdir -p ~/stroika-bot
   unzip -o ~/Downloads/stroika_telegram_bot.zip -d ~/stroika-bot
   cd ~/stroika-bot
   python3 --version
   ```

   Требуется Python 3.10 или новее. Если команда показала более старую версию или не найдена, установи Python с [официальной страницы для macOS](https://www.python.org/downloads/macos/). Затем настрой бота:

   ```bash
   python3 setup_mac.py
   ```

   Скрипт попросит **новый** токен. Его ввод скрыт. Для ID уже предложен `243705540`: нажми Enter, если он принадлежит твоему Telegram аккаунту. После успешной проверки токена запусти:

   ```bash
   python3 run_mac.py
   ```

   Если после установки Python команда `python3 --version` всё ещё показывает версию ниже 3.10, используй уже установленный `python3.15`: `python3.15 setup_mac.py`, затем `python3.15 run_mac.py`. При каждом новом запуске сначала выполняй `cd ~/stroika-bot`. Файл базы по умолчанию — `./data/ledger.sqlite3`.
3. Напиши боту `/start`. Перед первым расходом или приходом создай объект: `/project Дуплекс №1`. Можно создать ещё три объекта тем же способом. Кассы «Наличные», «Карта», «Счёт» уже созданы; своя касса добавляется `/account Название`.
4. Для произвольного периода введи `/report 2026-09-01 2026-09-30`. Скачай CSV кнопкой под отчётом.

Для длительной работы процесс должен быть постоянно запущен на твоём компьютере или сервере. Бот использует long polling: веб-адрес и домен не нужны. Если раньше был установлен webhook на этого же бота, удали его через метод `deleteWebhook` до запуска. Не запускай две копии с одним токеном и одной базой.

## Как читать цифры

«Вложения и займы» показывают, откуда профинансирована стройка; они не являются выручкой от продажи. «Изменение денег» = все внешние поступления − все расходы за выбранный период. Переводы между своими кассами в него не входят. «Остатки» учитывают все операции с начала ведения базы и не относятся к одному объекту. Отчёт и остатки выводятся отдельно для UAH и USD, автоматического пересчёта по курсу нет. При обновлении старые операции автоматически относятся к владельцу и сохраняют исходную валюту (записи старых гривневых версий — UAH).

На старте остаток каждой кассы равен нулю. Если деньги уже лежат в кассе, заведи их как «Приход» с источником «Личные средства» и понятным комментарием о начальном остатке. После добавления объектов и касс резервно копируй файл `ledger.sqlite3` вместе с его файлами `-wal` и `-shm` при остановленном боте либо через штатный SQLite backup API. Отчёт CSV не заменяет резервную копию базы и официальную бухгалтерию.

Бот хранит введённые суммы без учёта долгов и не принимает фото чеков. Свою сохранённую операцию можно открыть через кнопку «Операции», отредактировать или удалить после подтверждения; участники не меняют записи друг друга. Категории расходов и источников меняются в списках `STAGES`, `COST_TYPES`, `SOURCES` в начале `bot.py`.
